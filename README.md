# CodeAlpha Task 3 – Data Visualization

## Superstore Sales Analysis

This project is part of my CodeAlpha internship. The objective is to analyze Superstore sales data and create meaningful visualizations using Python.

## Objective

The project focuses on understanding sales performance across:

- Product Categories
- Regions
- Customer Segments
- Time Periods
- Category and Region combinations
- Individual order sales distribution

## Tools and Libraries

- Python
- Pandas
- Matplotlib
- Seaborn
- Excel

## Visualizations

The project includes the following visualizations:

1. Total Sales by Product Category
2. Total Sales by Region
3. Total Sales by Customer Segment
4. Monthly Sales Trend
5. Sales by Category and Region Heatmap
6. Sales Distribution

## Key Findings

- Sales performance varies across different product categories.
- Different regions contribute differently to overall sales.
- Customer segments have different levels of sales contribution.
- Monthly sales fluctuate over time.
- The category-region heatmap helps compare category performance across regions.
- The sales distribution shows how individual order values are spread across the dataset.

## Files

- `CodeAlpha_Task3_Data_Visualization.ipynb` – Main analysis notebook
- `sample_-_superstore.xls` – Superstore dataset
- `charts/` – Generated visualization charts

## Conclusion

Data visualization makes it easier to identify patterns, trends, and differences in sales data. The analysis can help support business decisions related to products, regions, customers, and sales performance.
